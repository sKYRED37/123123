# Развёртывание на bothost.ru

## Структура проекта

```
your-bot-repo/
├── bot.py               # точка входа (bothost по умолчанию ищет именно bot.py)
├── requirements.txt     # зависимости — ставятся автоматически через pip
├── .env.example         # шаблон переменных окружения
├── hots_rosters/        # сюда кладёте .txt файлы составов HotS
│   └── example_team.txt
└── README.md
```

## Шаги

1. Залейте эту папку в репозиторий на GitHub/GitLab.
2. На bothost.ru: «Создать бота» → «Git Deployment» → подключите репозиторий и ветку.
3. В разделе **Environment Variables** добавьте переменные из `.env.example`:
   - `BOT_TOKEN` — токен от @BotFather (обязательно)
   - `OWNER_ID` — ваш Telegram ID (обязательно, иначе не будут работать команды владельца)
   - `ANTHROPIC_API_KEY` — если используется
   - `HOTS_ROSTERS_DIR` — можно не трогать, по умолчанию `hots_rosters`
4. Нажмите «Deploy». bothost сам соберёт Docker-образ по `requirements.txt` и запустит `bot.py`.
5. После деплоя напишите боту `/start` — если всё ок, он ответит списком команд.

База данных — файл SQLite `esports_league.db`, создаётся автоматически рядом с `bot.py`
при первом запуске. Проверьте в настройках bothost, что диск/volume для контейнера
персистентный, иначе после каждого редеплоя данные (команды, игроки, статистика) обнулятся.

## Регистрация команд файлами (папка hots_rosters/)

Способ создать полноценную команду лиги (со всеми правами, что и через
`/create_team`), просто написав состав в текстовый файл — без длинных команд
в Telegram.

**Как это работает:**

1. Создаёте в папке `hots_rosters/` файл, например `liquid.txt`.
2. Первая строка файла — название команды, дальше — ровно 5 игроков основного
   состава, по одному на строке в формате `Ник Рейтинг Роль Возраст`:

   ```
   Team Liquid
   Nazeric 20.5 AWPer 24
   Glaurung 19.0 Rifler 22
   Snitch 18.5 Support 23
   Fan 17.5 Entry Fragger 21
   Bakery 18.0 IGL 25
   ```

   Роль берётся из того же списка, что и в `/create_team`: **Rifler, AWPer,
   Support, Entry Fragger, Lurker, IGL, Coach** (регистр не важен). Любая
   другая роль — ошибка, файл будет пропущен с пояснением.
   Строки, начинающиеся с `#`, игнорируются (можно оставлять комментарии).
   Опционально можно добавить секции `Резерв` (до 2 игроков) и `Тренер`
   (1 игрок, роль обязательно Coach) — так же, как в `/create_team`.
3. Дух и сыгранность команде выставляются автоматически по максимуму (100 и 50
   соответственно), ВРС — всегда 0. Указывать их в файле не нужно.
4. Составы подхватываются автоматически при каждом запуске бота, а также
   вручную командой `/hots_reload` (модераторам/админам) — без перезапуска.
5. Если команда с таким названием уже есть в лиге — файл пропускается (чтобы
   не затереть баланс, трансферы и текущую статистику существующей команды).
   Отредактировать состав уже созданной команды через файл нельзя — для этого
   есть обычные команды бота (`/transfer`, `/addroles` и т.д.).

**Команды в боте:**

- `/hots` — список команд, зарегистрированных из этой папки
- `/hots_reload` — пересканировать папку и зарегистрировать новые команды (только модераторы/админы)
- `/team_info [название]` — полная карточка любой зарегистрированной команды

Так как bothost пересобирает контейнер из репозитория при пуше, самый надёжный способ
добавлять составы — коммитить файлы в `hots_rosters/` в репозиторий и пушить;
bothost задеплоит их вместе с кодом, и они подхватятся при старте бота.
Если на хостинге доступна файловая панель/консоль контейнера — можно класть файлы
и через неё, а затем просто вызвать `/hots_reload`, не дожидаясь редеплоя.

## Магазин лиги (/shop)

Лидеры команд могут за баланс своей команды покупать улучшения:

| Товар | Цена | Эффект |
|---|---|---|
| 🏕 Буткемп | 600 000 | Винрейт команды в матчах +1…6% (случайно, накапливается) |
| 💻 Устройства | 300 000 | Сыгранность команды +5…10 (максимум 50) |
| 📱 Новые девайсы | 250 000 | Дух команды +5…10 (максимум 100) |

**Как пользоваться:** команда `/shop` показывает магазин кнопками. При нажатии на
товар бот сам определяет команду покупателя (если лидер ведёт несколько команд —
предложит выбрать), списывает цену с баланса команды, зачисляет её в банк лиги
и сразу показывает, насколько вырос показатель. Если денег не хватает — купить
не даст и покажет, сколько не хватает.

Бонус винрейта от буткемпа хранится в БД (колонка `winrate_boost` у команды),
накапливается с каждой покупкой и напрямую прибавляется к шансу команды выиграть
раунд в симуляции `/match` (в процентных пунктах, с учётом такого же бонуса
у соперника). Текущий накопленный бонус виден в `/team_info`.
