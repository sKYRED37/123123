# Это пример файла состава. Можно удалить или отредактировать.
# Первая непустая строка (без "#") — название команды.
# Дальше — по одному игроку на строке: Ник Рейтинг Роль Возраст
#
# Роль должна быть одной из ролей бота (как в /create_team, регистр не важен):
# Rifler, AWPer, Support, Entry Fragger, Lurker, IGL, Coach
#
# Основной состав — ровно 5 игроков. Дух и сыгранность выставляются
# автоматически по максимуму, ВРС всегда 0 — указывать их не нужно.
#
# Необязательно можно добавить секции "Резерв" (до 2 игроков) и "Тренер"
# (1 игрок, роль обязательно Coach), например:
#   Резерв
#   PlayerSix 16.0 Lurker 20
#   Тренер
#   CoachName 15.0 Coach 30
